## How you use the package

The C++ interface exposes `cyber_suite::<module>` targets through `find_package(cyber_suite)`. Python exposes supported bindings and native tools through `cyber_suite`; learning integrations also use the separate `cyber_suite_mjlab` adapter. Robot models and other packaged data are found through the package's data resolver. See the [package consumption boundary](../apps/README.md) for the current installation and build contract.

Hard real-time control belongs in C++20. Python supports training, research and analysis, as well as components without hard real-time constraints. Module lifecycle and available bindings vary; each block's owner contract identifies its supported surface.

<div class="package-boundary" markdown="1">

**Modules provide reusable mechanisms. Projects choose behavior.**

A robot project selects modules, connects them, supplies calibration and scenario settings, and defines the evidence needed to accept a result. Training recipes, robot-specific tuning and experiment outcomes stay with that project.

</div>

## See the pieces in an experiment

**Digit** is the most complete integration example, spanning model-based control, learned policies, CORTA and the Agility low-level interface. **Unitree G1** is the focused starting point for a student project. Their guides distinguish implementation from demonstrated simulation and hardware behavior.

[Explore Digit](../apps/digit/docs/overview.md) · [Start a G1 project](setup/student-projects.md) · [TRON1](../apps/tron1/docs/overview.md) · [Terrain mapping](../apps/perception/mapping/docs/overview.md)

New to robotics software? The [illustrated handbook](handbook/chapters/index.md) follows one command through the feedback loop, connects it to a recorded result and proposes a first exercise. The [first simulation guide](setup/first-run.md) then takes you into a viewer.

These guides explain design and use. Owner contracts describe implemented behavior; validation records describe demonstrated limits. Consult [repository status](status/CURRENT.md) for the current project-wide summary.
