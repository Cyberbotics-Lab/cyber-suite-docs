    Cyberbotics Lab / Software platform

    A shared foundation for robot behavior.¶

    Cyber Suite connects robot models, numerical methods, sensing, control and execution in a modular C++ and Python package. Use a single building block or compose an experiment whose behavior you can inspect.

    Explore the architecture → Learn with an example

    From method to experiment

    Model the system.

    Kinematics, dynamics and the numerical tools to reason about motion.

    Compose the behavior.

    State estimation, terrain queries, control algorithms and learned policies.

    Run and understand.

    Execution, world interfaces and recorded evidence of what happened.

    How you use the package¶

    The C++ interface exposes cyber_suite::<module> targets through find_package(cyber_suite). Python exposes supported bindings and native tools through cyber_suite; learning integrations also use the separate cyber_suite_mjlab adapter. Robot models and other packaged data are found through the package's data resolver. See the package consumption boundary for the current installation and build contract.

    Hard real-time control belongs in C++20. Python supports training, research and analysis, as well as components without hard real-time constraints. Module lifecycle and available bindings vary; each block's owner contract identifies its supported surface.

    Modules provide reusable mechanisms. Projects choose behavior.

    A robot project selects modules, connects them, supplies calibration and scenario settings, and defines the evidence needed to accept a result. Training recipes, robot-specific tuning and experiment outcomes stay with that project.

    See the pieces in an experiment¶

    Digit is the most complete integration example, spanning model-based control, learned policies, CORTA and the Agility low-level interface. Unitree G1 is the focused starting point for a student project. Their guides distinguish implementation from demonstrated simulation and hardware behavior.

    New to robotics software? The illustrated handbook follows one command through the feedback loop, connects it to a recorded result and proposes a first exercise. The first simulation guide then takes you into a viewer.

    These guides explain design and use. Owner contracts describe implemented behavior; validation records describe demonstrated limits. Consult repository status for the current project-wide summary.
